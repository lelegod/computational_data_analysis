Expected Prediction Error (EPE), Bias & Variance

The Bias-Variance Decomposition

EPE = Bias² + Variance + Irreducible Error (σ²)
  • Bias = E[f̂(x)] − f(x) — how far off on average across all training sets. Decreases with model complexity.
  • Variance = E[(f̂(x) − E[f̂(x)])²] — how much the model changes with different training data. Increases with complexity.
  • Irreducible error (σ²) = noise in the data-generating process. Cannot be reduced by ANY model regardless of complexity.
★ Exam favourite
Irreducible error is NOT affected by model complexity. Bias and variance are. EPE and generalization error differ: EPE = expectation over training sets; generalization error = conditioned on a fixed training set.
Regularization and bias-variance
  • Large λ → heavy penalty → model too simple → high bias, low variance (underfitting)
  • Small λ → little penalty → model too flexible → low bias, high variance (overfitting)
  • Both high bias AND low bias can be stated simultaneously when describing an overfitting model: small λ → high variance + low bias

Collinearity

When input variables are highly correlated, OLS estimates become unstable — small changes in data cause large swings in coefficients. Variance of estimates explodes.

  • Ridge regression directly addresses collinearity by adding λ‖β‖₂² — shrinks correlated coefficients together
  • PCA can remove collinearity by working in orthogonal principal component space

OLS and Ridge Regression

Ordinary Least Squares (OLS)

β̂ = (XᵀX)⁻¹XᵀY
  • Requires XᵀX to be invertible → fails when p ≥ n or when variables are collinear
  • BLUE (Best Linear Unbiased Estimator) when Gauss-Markov assumptions hold
  • Zero bias but can have very high variance

Ridge Regression

β̂_ridge = argmin ‖y − Xβ‖₂² + λ‖β‖₂² = (XᵀX + λI)⁻¹XᵀY
  • Closed form solution exists — (XᵀX + λI)⁻¹XᵀY
  • Adding λI makes the matrix invertible even with collinearity or p > n
  • Shrinks ALL coefficients toward zero but never exactly to zero → no feature selection
  • L2 penalty: circular constraint region → no corners → no exact zeros
Why ridge does NOT do feature selection
The L2 (ridge) constraint region is a smooth sphere. The optimal solution lies on this sphere, which has no corners at the axes. Lasso's L1 constraint is a diamond shape with corners ON the axes — the optimal solution often hits a corner, setting coefficients exactly to zero.

K-Nearest Neighbors (KNN)

Non-parametric Classification & Regression
  • Predicts by taking the majority class (classification) or mean (regression) of the K nearest training points
  • Small K → complex, wiggly boundary → low bias, high variance → overfitting
  • Large K → smooth boundary → high bias, low variance → underfitting → good weak learner for boosting
  • No training phase — all computation at prediction time ("lazy learner")
  • Sensitive to scale of features → always standardize
  • Suffers from curse of dimensionality
KNN in bagging vs boosting
  • Bagging: use KNN with small K (high variance) — bagging reduces variance
  • Boosting: use KNN with large K (high bias, weak learner) — boosting reduces bias

K-means Clustering

Unsupervised
Minimize: Σₖ Σᵢ∈Cₖ ‖xᵢ − μₖ‖²

Algorithm: (1) Initialize K centroids randomly. (2) Assign each point to nearest centroid. (3) Recompute centroids as mean of assigned points. (4) Repeat until convergence.

  • Assumes spherical, equal-sized clusters (implicit from Euclidean distance)
  • Hard assignments — each point belongs to exactly one cluster
  • Sensitive to outliers (mean is pulled by extremes)
  • Result depends on initialization — run multiple times
  • NOT a matrix factorization method
  • Cannot use AIC/BIC to select K (no likelihood model)
  • Use elbow method or silhouette scores to select K

Model Selection: CV, Bootstrap, AIC, BIC

Cross-Validation (CV)

  • Split data into K folds; train on K-1, test on 1; rotate; average error
  • Estimates Expected Prediction Error (EPE)
  • Critical rule: Normalization/standardization must be done INSIDE each fold — computing on full data before CV causes information leakage
  • Assumes data are IID (independently and identically distributed)
  • When data has structure (groups, time), keep dependent observations in same fold
Common CV mistakes (exam traps!)
  • Standardizing before CV → leakage from test fold into training
  • Using random CV when data has grouped/time-series structure → overly optimistic estimates
  • Using CV for both model selection AND assessment → biased → use nested CV instead

Nested (Double-loop) Cross-Validation

  • Inner loop: selects hyperparameters (model selection)
  • Outer loop: estimates generalization error (model assessment)
  • Use when you want an unbiased estimate of generalization error after hyperparameter tuning

One-Standard-Error Rule

Find the minimum-error model, compute its standard error. Select the simplest model whose error is within 1 SE of the minimum. Favors parsimony when models perform similarly.

Lasso and Elastic Net

Lasso (L1 regularization)

β̂ = argmin ‖y − Xβ‖₂² + λ‖β‖₁    where ‖β‖₁ = Σ|βᵢ|
  • No closed form solution — L1 penalty not differentiable at zero
  • Solved numerically via coordinate descent or LARS (Least Angle Regression)
  • Does feature selection — sets some coefficients exactly to zero
  • Diamond-shaped constraint region with corners on axes → optimal solution hits corners → exact zeros
  • LARS is a path algorithm: computes full solution for all λ in one pass
  • Handles p >> n well

Elastic Net

β̂ = argmin ‖y − Xβ‖₂² + λ₁‖β‖₁ + λ₂‖β‖₂²
  • Combines L1 (lasso) and L2 (ridge) penalties
  • Feature selection (from L1) + handles correlated variables (from L2)
  • Best of both worlds for p >> n with correlated features

Multiple Testing: Bonferroni, BH, FDR

When running M hypothesis tests, the probability of at least one false positive grows. If each test has significance level α, the chance of ANY false positive ≈ 1 − (1−α)ᴹ.

Bonferroni Correction

  • Use significance level α/M for each individual test
  • Controls Family-Wise Error Rate (FWER) = P(at least one false positive)
  • Very conservative — suitable when ANY false positive is unacceptable
  • Can be too conservative when M is very large → misses real effects

Benjamini-Hochberg (BH) Algorithm

  • Controls False Discovery Rate (FDR) = E[false positives / total positives]
  • Less conservative than Bonferroni → more discoveries, some false positives tolerated
  • Algorithm: sort p-values p₍₁₎ ≤ p₍₂₎ ≤ … ≤ p₍ₘ₎; reject all H₍ₖ₎ where k ≤ max{i: p₍ᵢ₎ ≤ αi/M}
  • Controls upper bound of FDR
BonferroniBenjamini-Hochberg

★ Exam key distinction
BH controls the expected proportion of false discoveries (FDR). Bonferroni controls the probability of at least one false discovery (FWER). At the same α level, BH gives MORE significant findings AND more false positives than Bonferroni.

Linear Discriminant Analysis (LDA) and QDA

Supervised Probabilistic

LDA Assumptions

  • Each class k follows a multivariate Gaussian: p(x|k) ~ N(μₖ, Σ)
  • All classes share the same covariance matrix Σ (homoscedasticity)
  • This shared covariance is why the boundary is linear — quadratic terms cancel
Why is LDA linear?
When computing the log posterior ratio log[P(k₁|x)/P(k₂|x)], the term xᵀΣ⁻¹x appears in both numerators and cancels (because Σ is shared). What remains is a linear function of x → linear decision boundary. If covariances differ → QDA → quadratic boundaries.

LDA Fitting (closed form)

  • μ̂ₖ = class mean for class k
  • Σ̂ = pooled within-class covariance = (1/(n−K)) Σₖ Σᵢ∈ₖ (xᵢ−μₖ)(xᵢ−μₖ)ᵀ
  • π̂ₖ = nₖ/n (class prior)

QDA

  • Relaxes equal covariance assumption — each class has its own Σₖ
  • Quadratic terms do NOT cancel → quadratic decision boundary
  • More flexible than LDA but more parameters to estimate → needs more data

Logistic Regression

Supervised Probabilistic
P(Y=1|x) = 1 / (1 + exp(−βᵀx)) = σ(βᵀx)
  • Models posterior probability P(class|x) directly — discriminative approach
  • Probabilistic method (like LDA, unlike SVM)
  • Without regularization: fails when p ≥ n — design matrix is rank deficient
  • With L1/L2 regularization: handles p >> n
  • Estimated by maximizing likelihood (no closed form — numerical optimization)

ROC Curves

  • Plots True Positive Rate (sensitivity) vs False Positive Rate (1-specificity) at all thresholds
  • AUC = Area Under Curve — higher is better (1 = perfect, 0.5 = random)
  • Threshold-independent performance metric

CART — Decision Trees

Non-parametric

Building a tree

  • Recursively split features to minimize impurity (Gini index or entropy for classification; RSS for regression)
  • At each node, find the split that gives the largest reduction in impurity
  • Grow until leaves are pure or minimum leaf size is reached

Pruning

Pruning = removing splits from a grown tree to prevent overfitting. A split is removed by replacing it and its children with a single leaf node, which predicts the majority class (classification) or mean value (regression) for all observations reaching it.

Cost-complexity pruning

For each node, compute: α = (error if pruned − error of subtree) / (leaves in subtree − 1)

Prune the node with the smallest α first (smallest impurity reduction = weakest split). Continue until desired complexity. Use cross-validation to choose how far to prune.

Example: reductions = 4, 3.5, 5, 8 → prune at 3.5 first, then 4, then 5, keep 8 longest.

  • Full trees: low bias, high variance (overfitting)
  • Pruned/stumped trees: higher bias, lower variance
  • Handles categorical variables natively (no one-hot encoding needed)

Bagging (Bootstrap Aggregating)

  • Train B trees on B bootstrap samples (sample with replacement)
  • Average predictions (regression) or majority vote (classification)
  • Reduces variance without changing bias
  • Works best with high-variance models (deep trees, KNN with small K)
  • Stumps (high bias, low variance) don't benefit much from bagging
  • Trees are independent → can be parallelized

Boosting (AdaBoost, Gradient Boosting)

Supervised

Forward Stagewise Additive Modelling

  • Sequentially add weak learners, each focusing on the errors of the previous ensemble
  • Fixed previously added trees — old trees are never updated, only new ones added
  • Each new learner gets a weight based on how well it corrects current errors

AdaBoost

  • Re-weights misclassified observations more heavily after each round
  • Equivalent to forward stagewise additive modelling with exponential loss
  • Exponential loss gives exponentially higher weight to misclassified points → very aggressive

Suitable weak learners for boosting

  • Tree stumps (depth-1 trees) — canonical weak learner
  • KNN with large K — smooth, high bias, low variance
  • NOT deep trees (strong learners with low bias — boosting doesn't need them)
  • NOT KNN with small K (high variance — wrong type of weakness)

Random Forests

Supervised

Algorithm

  1. Draw B bootstrap samples
  2. For each sample, grow a fully grown tree
  3. At each split, consider only m randomly chosen variables (typically m = √p for classification, p/3 for regression)
  4. Average predictions over all B trees

Key properties

  • Variance of RF = variance of single tree × decorrelation factor — smaller m → more decorrelated trees → more variance reduction
  • Bias of RF = bias of individual tree — RF does not change bias; use deep trees (low bias)
  • Trees are independent → fully parallelizable
  • Handles p >> n well
  • OOB (out-of-bag) samples ≈ 1/3 of data → free internal validation
★ Key exam fact: smaller m → more variance reduction (not less)
Smaller m decorrelates trees more. More decorrelation → more variance reduction. The exam question in 2024 had a wrong statement saying "small m leads to smaller variance reduction" — this is FALSE.

Variable Importance

  • Gini importance: sum of Gini impurity decreases at all splits involving variable j across all trees
  • OOB importance: permute variable j in OOB samples; measure drop in accuracy. Uses all trees, evaluated on OOB samples
  • Proximity plots: measure closeness of OBSERVATIONS (how often they end up in same leaf) — NOT variables

Support Vector Machines (SVM)

Supervised

Core idea

Find the hyperplane that separates classes with the maximum margin. Only the training points on or within the margin (support vectors) determine the boundary.

  • With linear kernel → linear classifier
  • With non-linear kernel (RBF, polynomial) → non-linear classifier in original space
  • Linearity depends on the chosen kernel

The Kernel Trick

What the kernel trick does
Replaces explicit computation of φ(x) (a potentially infinite-dimensional feature map) with a kernel function K(xᵢ, xⱼ) = φ(xᵢ)ᵀφ(xⱼ). You compute in a high-dimensional space without ever computing the transformation explicitly — only pairwise inner products are needed.

Methods that admit kernel trick

  • SVM — dual formulation is in terms of dot products → kernel trick applies directly
  • Kernel PCA — PCA can be kernelized (performs PCA in the kernel feature space)
  • NOT Boosting (no inner products in formulation)
  • NOT Random Forest (tree splits, not inner products)

PCA and Sparse PCA (SPCA)

Unsupervised

PCA

  • Finds orthogonal directions of maximum variance (principal components)
  • PC1 explains the most variance, PC2 the second most, etc.
  • Eigenvalues of covariance matrix = variance explained by each PC
  • Fraction explained by PCₖ = λₖ / Σλᵢ
  • Handles p >> n (eigendecomposition works even when p > n)
  • Matrix factorization method: X ≈ UDVᵀ (SVD)
  • Produces uncorrelated components (but not necessarily independent)
★ PCA variance example (2025 exam)
X ∈ ℝ¹⁰⁰ˣ², eigenvalues λ₁=6, λ₂=2. Fraction explained by PC1 = 6/(6+2) = 75%.

Hierarchical Clustering

Unsupervised
  • Agglomerative (bottom-up): start with each point as its own cluster, merge closest pairs. Most common.
  • Divisive (top-down): start with all points in one cluster, split recursively.
  • Agglomerative vs divisive is determined by the algorithm choice, NOT the linkage function
  • Linkage function determines how to measure distance BETWEEN clusters (single, complete, average, Ward's)
  • Accepts any distance metric (Manhattan, Euclidean, correlation-based, etc.)
  • Produces a dendrogram — cut at any height to get desired number of clusters
  • Does NOT require specifying K in advance → useful when number of groups is unknown
Why hierarchical clustering for the airport face recognition question (2022 Q22)
You don't know K (number of unique people) in advance. Hierarchical clustering builds the full dendrogram and you cut it at a threshold. Each cluster = one unique person. Compare number of clusters to number of passport numbers to detect fraud.

Distance metrics for clustering

  • Euclidean distance: standard L2 distance — assumes continuous variables
  • Manhattan distance: L1 distance between continuous variables (NOT for categorical)
  • Gower distance: for mixed variable types including categorical
  • Hamming distance: for categorical/binary variables

Gaussian Mixture Models (GMM)

Unsupervised Probabilistic
p(x) = Σₖ πₖ · N(x | μₖ, Σₖ)
  • Probabilistic model — assigns soft membership probabilities to each component
  • Each component has its own covariance Σₖ → can model elliptical clusters
  • Fitted with EM algorithm (Expectation-Maximization)
  • E-step: compute soft assignments rᵢₖ = P(component k | xᵢ)
  • M-step: update μₖ, Σₖ, πₖ using weighted averages
  • Repeat until log-likelihood converges
  • Can use AIC or BIC to select number of components

Gap Statistics and Silhouette Plots

Silhouette coefficient

s(i) = (b(i) − a(i)) / max(a(i), b(i))

where a(i) = mean distance to points in same cluster, b(i) = mean distance to points in nearest other cluster.

  • s(i) close to 1 → well-clustered
  • s(i) close to 0 → on boundary between clusters
  • s(i) negative → probably in wrong cluster
  • Choose K where average silhouette is highest and no cluster has many negative values
★ Silhouette plot exam tip (2025)
Look for: (1) highest average silhouette coefficient AND (2) all clusters uniformly above the average (no cluster dipping below). In the 2025 exam, k=4 was optimal — all four clusters had high, uniform silhouette values around 0.9.

Artificial Neural Networks (ANN)

Architecture

  • Input layer → hidden layers (with activation functions) → output layer
  • Common activations: ReLU, sigmoid, tanh
  • Each connection has a weight; each node has a bias

Parameter counting

Formula: for each layer, count (inputs × outputs) + outputs (biases)

Example: 3 inputs → 4 hidden (ReLU) → 2 hidden (ReLU) → 1 output (linear), all with biases:

  • Layer 1: 3×4 + 4 = 16
  • Layer 2: 4×2 + 2 = 10
  • Output: 2×1 + 1 = 3
  • Total = 29

Another example from 2024: 10 inputs → 2 hidden (2 units each) → 1 output = (10×2+2)+(2×2+2)+(2×1+1) = 22+6+3 = 31

  • Neural networks can overfit (contrary to common misconception)
  • Regularization: dropout, weight decay, early stopping
  • Trained via backpropagation (gradient descent)

Autoencoders

Unsupervised
  • Encoder compresses input to a low-dimensional bottleneck representation
  • Decoder reconstructs the input from the bottleneck
  • Loss = reconstruction error (difference between input x and output x̂)
  • No labels needed — learns a compressed representation unsupervised
  • Bottleneck forces learning of meaningful features

Non-Negative Matrix Factorization (NMF)

Unsupervised
X ≈ WH   where all entries of W and H ≥ 0
  • Both W and H must have non-negative entries — defining constraint
  • Allows only additive combinations → parts-based representation (e.g. facial features)
  • Does NOT guarantee unique factorization
  • Does NOT require orthogonality
  • Applied to non-negative data (images, text counts, etc.)
  • Data must be non-negative for NMF to be meaningful (cannot apply to data with negative values without shifting)

Archetypal Analysis (AA)

Unsupervised
  • Archetypes = weighted combinations of extreme data points (lie on convex hull of data)
  • Each data point = convex combination of archetypes (weights ≥ 0, sum to 1)
  • Finds "pure types" at the extremes — every observation is a mixture of extremes
  • VE (Variance Explained) measures how well the archetypes capture the data
  • Contrasts with PCA (finds directions of variance, not extremes) and K-means (finds central cluster points)

Independent Component Analysis (ICA)

Unsupervised

Goal

Recover statistically independent source signals S from observed mixtures X = AS (where A is an unknown mixing matrix).

Independence vs uncorrelatedness

  • Uncorrelated: E[s₁s₂] = E[s₁]E[s₂] — only captures linear relationships
  • Independent: p(s₁, s₂) = p(s₁)·p(s₂) — joint distribution factorizes — captures ALL dependencies
  • Independence is stronger than uncorrelatedness

Why non-Gaussian distributions?

By the Central Limit Theorem, mixtures of signals tend toward Gaussian. So X = AS is MORE Gaussian than the original sources S. ICA recovers sources by finding directions of maximum non-Gaussianity (measured by kurtosis or negentropy). A purely Gaussian source cannot be recovered by ICA.

Ambiguities of ICA (non-uniqueness)

  • Permutation ambiguity: order of recovered components is unknown
  • Sign ambiguity: sign of each component is indeterminate (s or −s)
  • Scale ambiguity: variance of each component cannot be determined independently

Apart from these three, ICA IS unique when sources are non-Gaussian and truly independent.

Why ICA recovers sources PCA cannot
PCA finds uncorrelated directions of maximum variance — but uncorrelated ≠ independent for non-Gaussian distributions. ICA exploits higher-order statistics (non-Gaussianity) to find truly independent components. Classic example: cocktail party problem (separating overlapping audio signals).

Multiway Models: PARAFAC and Tucker

Tucker decomposition

  • Decomposes a multiway tensor X into component matrices for each mode and a core tensor G
  • Core tensor G has dimensions R₁ × R₂ × R₃ (for 3-way) — these define the rank in each mode
  • More flexible than PARAFAC — different ranks in each mode

PARAFAC (CP decomposition)

  • Special case of Tucker where core tensor is super-diagonal (identity-like tensor)
  • All modes have the same number of components
  • More constrained than Tucker

CORCONDIA (Core Consistency Diagnostic)

CORCONDIA = 100 · (1 − ‖ℐ − G̃‖²F / ‖ℐ‖²F)
  • Compares the Tucker core tensor G̃ to the super-diagonal identity tensor ℐ
  • CORCONDIA close to 100 → core is close to super-diagonal → PARAFAC model is appropriate with the chosen number of components
  • Used to select the NUMBER OF COMPONENTS in PARAFAC (not to choose between PARAFAC and Tucker)
  • Choose the highest number of components where CORCONDIA remains high
  • ℐ is a super-diagonal identity tensor (not just a "diagonal matrix" — that description is too imprecise for a tensor)
★ 2022 Q16: Answer is E (None of the above)
A says ℐ is "a diagonal matrix" — too imprecise, it's a super-diagonal tensor. B, C, D are also wrong for the reasons described above. The answer is E.

Common Exam Traps

Trap 1 — Regularization direction
Large λ = high bias (underfitting). Small λ = high variance (overfitting). Both high variance AND low bias are simultaneously true for small λ.
Trap 2 — Lasso has no closed form
Ridge has closed form (XᵀX + λI)⁻¹XᵀY. Lasso does NOT — L1 is non-differentiable at zero. Solved numerically.
Trap 3 — CV standardization
Always standardize INSIDE each fold, not before CV. Pre-standardizing causes information leakage from test fold.
Trap 4 — Agglomerative vs divisive
The linkage function does NOT decide agglomerative vs divisive. That is determined by the algorithm. Linkage decides how to measure cluster-to-cluster distance within agglomerative clustering.
Trap 5 — RF parallelization
Random Forest CAN be parallelized (trees are independent). Boosting CANNOT (sequential, each tree depends on previous).
Trap 6 — RF variance and m
Smaller m (fewer variables at each split) → MORE decorrelation → MORE variance reduction. The 2024 exam had a wrong statement saying small m gives SMALLER variance reduction.
Trap 7 — CART and categorical variables
CART handles categorical variables natively by grouping categories at splits. It does NOT one-hot encode them.
Trap 8 — SVM dual formulation ≠ nonlinear
The dual formulation alone does not give nonlinear boundaries. Nonlinearity comes from using a non-linear kernel in the dual.
Trap 9 — K-means distance metric for categorical
Manhattan distance is NOT for categorical variables — it measures absolute distance between continuous variables. Use Gower or Hamming for categorical data.
Trap 10 — Proximity plots in RF
Proximity plots measure closeness of OBSERVATIONS (how often two observations land in the same leaf), NOT closeness of variables.
Trap 11 — CCA orthogonality
PCA and PLS impose orthogonality on latent variables. CCA does NOT necessarily produce orthogonal variates.
Trap 12 — NMF and negative data
NMF requires data to be non-negative (or shifted to be non-negative). Cannot apply directly to data with negative values.
